# Local imports only (ignored by Git)

- `figma.json`: JSON exported using an approved method, optional.
- `design.fig`: offline Figma design file, optional (OpenFig parses it).
- `export.zip`: manual export from `Baolv/figma-export` plugin, optional.
- `figma-expected.png`: genuine matching-scope/size Figma PNG to compare with React screenshot.

Do not put confidential or government data in public version-control. For precise visual audit, use the same design scope (component vs component) and same screenshot pixel dimensions. Do not silently resize / crop or call Figma API.
