# تنزيل تصميم Figma على Windows بدون إضافة وبدون REST API

المسار المعتمد:

**لوحة React → رابط التصميم → متصفح Playwright ظاهر → Main menu → File → Save local copy → ملف `.fig` → OpenFig → المقارنة**

رابط Figma وحده لا يفتح الملف. أول مرة يحتاج الحساب إلى تسجيل دخول داخل النافذة التي يفتحها التطبيق.

## ما يفعله المستخدم

1. ثبّت Node.js 22 أو أحدث، ثم من مجلد المشروع:
   ```powershell
   npm.cmd install
   npx.cmd playwright install chromium
   npm.cmd run dev
   ```
2. افتح `http://127.0.0.1:5173`. خادم `vite preview` لا يشغّل جسر التنزيل.
3. الصق رابط ملف Design يحتوي `node-id`.
4. اضغط **تنزيل التصميم**.
5. في النافذة الظاهرة سجّل الدخول بنفسك. لا يكتب التطبيق كلمة المرور ولا يقرأ ملفات تعريف الارتباط.
6. اترك النافذة مفتوحة حتى يُغلقها التطبيق بعد الحفظ.
7. للتحديث بعد تعديل التصميم اضغط **تحديث التصميم**.

الجلسة تبقى في `.browser-profile` داخل المشروع، وهذا المجلد مستبعد من Git. الملفات النازلة تُحفظ في `input/downloads/`.

## ما يفعله التطبيق

- يتحقق أن الرابط `https://www.figma.com/design/...` وفيه `node-id`.
- يرفض FigJam والروابط الخارجية وحقول الجلسة في الطلب.
- يفتح Chrome إن كان مثبتًا، وإلا Chromium الخاص بـ Playwright.
- ينقر Main menu ثم File ثم Save local copy.
- يقبل الملف فقط إذا كان أرشيف `.fig` واستطاع OpenFig قراءته واستخراج العقدة.
- إذا كان الأمر معطّلًا أو غائبًا تتوقف العملية برسالة، ولا يُعرض نجاح.

## ما لا يُستخدم

- إضافة Figma Fidelity Connector ورمز الاقتران. الملفات القديمة ما زالت في المستودع لكنها ليست مسار التشغيل.
- Figma REST API.
- Baolv/figma-export كأداة جلب. يمكن استيراد ZIP سابق يدويًا، وهذا لا يغني عن التنزيل من المتصفح.

## نتيجة الفحص على هذا الجهاز في 4 نوفمبر 2026

فتح المتصفح على الرابط التجريبي ثم توقفت العملية لأن تسجيل الدخول لم يكتمل خلال 48 ثانية. الحالة: `login_timeout`. لا يوجد ملف `.fig` من هذا التشغيل.
