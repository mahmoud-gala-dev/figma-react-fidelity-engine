# دليل التشغيل المباشر عبر أتمتة المتصفح على Windows (Direct Browser Automation)

## 1. الفكرة الأساسية ومزايا الأتمتة المباشرة

تم الاستغناء بالكامل عن الإضافات (Plugins)، وأكواد الاقتران (Pairing Codes)، وملفات ZIP اليدوية، والاعتماد على السحب المباشر بواسطة **أتمتة المتصفح المحلي (Playwright Browser Automation)** عبر الخطوات التالية:

**رابط Figma في اللوحة → تشغيل متصفح محلي آمن → تنفيذ أمر File: Save local copy → تنزيل ملف .fig → فك وتطبيع العقد بـ OpenFig Core → إجراء المقارنة**

---

## 2. كيفية الاستخدام خطوة بخطوة

### الخطوة 1: تشغيل خادم التطوير المحلي
```powershell
npm.cmd run dev
```
افتح اللوحة في المتصفح عبر الرابط: `http://127.0.0.1:5173`.

---

### الخطوة 2: لصق الرابط والضغط على «تحميل التصميم من Figma»
1. في لوحة التحكم، ألصق رابط تصميم Figma المعتمد:
   ```
   https://www.figma.com/design/vMYpz8Jc3EzVUsLQCDx3Jd/essam-qutb-s-team-library?node-id=0-1
   ```
2. اضغط على زر **«تحميل التصميم من Figma»**.

---

### الخطوة 3: تسجيل الدخول التفاعلي لمرة واحدة فقط (First-Time Login)
- في أول تشغيل فقط، سيفتح المتصفح المحلي نافذة مرئية.
- إذا لم تكن مسجل الدخول، ستظهر لك صفحة تسجيل الدخول لـ Figma في النافذة.
- ستظهر لك في اللوحة رسالة: **«بانتظار تسجيل دخولك في نافذة المتصفح المفتوحة...»**.
- قم بتسجيل الدخول بحسابك بشكل طبيعي.
- بمجرد اكتمال تسجيل الدخول، ستقوم الأتمتة فوراً بمتابعة فتح ملف التصميم.
- **يتم حفظ الجلسة محلياً داخل مجلد `.browser-profile/` على جهازك فقط**، وفي المرات القادمة لن يُطلب منك تسجيل الدخول مجدداً!

---

### الخطوة 4: حفظ النسخة المحلية واستخراج الخصائص آلياً
- يقوم المتصفح آلياً بتنفيذ أمر Figma الرسمي:
  **`File → Save local copy...`**
- يستلم محرك Playwright ملف الـ `.fig` المكتمل ويحفظه في مجلد `input/downloads/`.
- يتحقق النظام من صحة توقيع ملف Figma.
- يقوم محرك **OpenFig Core** بقراءة شجرة العقد والأبعاد والخطوط والألوان وتطبيع العقدة المحددة بالـ `node-id`.
- تلتقط الأداة لقطة شاشة مرجعية حقيقية من المتصفح لاستخدامها في المقارنة البصرية عبر Pixelmatch و reg-cli.
- تُعرض النتائج والمؤشرات وجدول الفروقات فوراً في لوحة التحكم!

---

### الخطوة 5: تحديث التصميم بنقرة واحدة (Refresh Design)
إذا طرأ أي تغيير على التصميم في Figma:
- اضغط مباشرة على زر **«تحديث التصميم»**.
- سيقوم المتصفح بإعادة التنزيل واستخراج الخصائص وتحديث جدول الفروقات وسجل التعديلات تلقائياً.

---

## 3. معالجة الحالات الاستثنائية (Error Handling)

| الحالة | سببها | رسالة النظام والإجراء المطلوب |
|---|---|---|
| **انتهاء مهلة تسجيل الدخول** | عدم إكمال تسجيل الدخول خلال 120 ثانية. | تظهر رسالة تطلب تسجيل الدخول في المتصفح ثم إعادة النقر على تحميل التصميم. |
| **صلاحيات التصدير معطلة (View Only بدون حفظ)** | صاحب الملف عطل خيار حفظ نسخة محلية. | ينبه النظام بأن أمر حفظ نسخة محلية غير متاح للملف؛ يلزم استخدام حساب يملك صلاحية التعديل أو عمل Duplicate للملف في مسوداتك. |
| **رابط FigJam (`/board/`)** | اختيار رابط سبورة بيضاء بدلاً من تصميم. | يتم رفض الرابط مع توجيه المستخدم لنسخ رابط تصميم من ملف Figma Design قياسي (`/design/`). |
| **الملف غير موجود (404)** | مفتاح الملف غير صالح أو تم حذفه. | يوضح المتصفح أن الملف غير موجود أو لا توجد صلاحية للوصول إليه. |
