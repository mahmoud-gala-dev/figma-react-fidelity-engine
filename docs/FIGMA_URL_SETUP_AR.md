# رابط Figma في نسخة الـMVP

## لماذا لم يكن موجودًا؟
الإصدار السابق كان Offline-first، يحتوي على استيراد JSON فقط. هذه النسخة تضيف خانة رابط التصميم، وتحلل fileKey وnode-id، وتستطيع تحميل آخر Full ZIP **موجود محليًا** لمصدر مطابق.

## الخطوات على Windows (لا REST API)

1. شغّل المشروع عبر `npm install` ثم `npm run dev`.
2. افتح Figma Desktop وصلاحيتك على التصميم؛ حدّد العنصر نفسه وانسخ **Copy link to selection**.
3. ألصق الرابط في خانة «رابط تصميم Figma» داخل React واضغط «تحليل الرابط».
4. شغّل إضافة [Baolv/figma-export](https://github.com/Baolv/figma-export) من Figma Desktop، ثم اختر **Full Export** واحفظ ZIP الناتج.
5. إمّا ارفع ZIP من زر «اختيار JSON / ZIP»، أو انسخه إلى مجلد `input/figma-exports/` واضغط «جلب آخر تصدير محلي».
6. بعد تعديل التصميم في Figma: صدّر Full ZIP جديدًا وأضفه إلى المجلد، ثم اضغط نفس الزر. لن يحدث اتصال تلقائي بسحابة Figma في Windows بهذه النسخة.

## ما الذي يفعله الرابط؟
- يحدد `fileKey`، للتأكد أن ZIP ينتمي إلى ملف Figma المقصود.
- يحدد `node-id`، للبحث عن العنصر داخل export وعدم اختيار عنصر غير صحيح.
- **لا** يحمّل التصميم من موقع figma.com وحده؛ هذه عملية تحتاج آلية اتصال معتمدة، وإضافة Figma Export تعمل في Figma Desktop.

## ملاحظات
- `node-id=0-1` عادة يشير إلى صفحة؛ الأفضل أن تنسخ رابط *العنصر/الإطار المختار* بدل صفحة عامة.
- مكوّن ``/api/local-figma-export`` يعمل في Vite dev server فقط. نشر الإنتاج يحتاج Node/Express backend منفصلًا، وليس جزءًا من هذا التصحيح.
- لملفات `.fig` المحلية استعمل `npm run extract:fig` الموجود أصلًا في المشروع؛ OpenFig ليست أداة لسحب تصميم Figma السحابي.
- ملف ZIP التجريبي في `fixtures/` لا يخص رابط تصميمك الحقيقي؛ لا تختبره على أنه مزامنة حقيقية.
